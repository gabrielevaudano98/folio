# Getting started with Folio

This tutorial takes about ten minutes. At the end you will have a folder of notes, a page with a link and a table, and an
AI assistant that can read them.

1. **Open a folder.** Start Folio and choose **Open folder**. Pick an empty folder, for example `Documents/Notes`. Folio
   keeps everything as Markdown files in it.
2. **Make a page.** Press `Ctrl+N` (`Cmd+N` on a Mac), name it *Project ideas* and write a few lines. `Ctrl+B`, `Ctrl+I`
   and `Ctrl+L` make bold, italic and a checklist.
3. **Link two pages.** Write `[[Meeting notes]]`. Choose the link: Folio offers to create the page. The other page now
   lists this one under *Linked from*.
4. **Switch views.** `Ctrl+1` writes, `Ctrl+2` shows Markdown and preview side by side, `Ctrl+3` reads.
5. **Connect an AI assistant.** Open **AI → Connect AI Assistants…** (`Ctrl+Shift+A`), pick yours (Claude Desktop, Claude Code, Cursor…)
   and choose **Connect**. Restart that app, then ask it: *"List my notes in Folio and summarise Project ideas."*
6. **Watch an AI edit.** Ask it to add a heading to your page. The change appears highlighted, with **Undo**.
